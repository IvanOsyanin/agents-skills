# Общие скиллы агентов

Кастомные скиллы для повторного использования в OpenCode, Cursor и Codex. Каталог репозитория соответствует `~/.agents/skills`.

## Содержимое

- `code-review/` — структурированное ревью кода с учётом форматов Cursor и Codex.
- `execute-plan/` — пошаговое выполнение согласованных планов с подтверждением этапов.
- `otar-diagrams/` — создание схем ОТАР по коду; включает правила, справочные материалы, редактируемые образцы, изображения и скрипт проверки/сборки ресурсов.

У каждого скилла есть `SKILL.md`; дополнительные материалы хранятся рядом в его каталоге.

Перед редактированием на устройстве подтяните изменения (`git pull`). После изменений сохраните их коммитом и отправьте (`git push`), чтобы получить их на другом компьютере.
