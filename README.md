# Общие скиллы агентов

Пользовательские скиллы для повторного использования в OpenCode, Cursor и Codex. Каталог репозитория соответствует `~/.agents/skills`.

## Скиллы

- [`gitnexus/`](gitnexus/SKILL.md) — исследование и анализ связей в кодовой базе через GitNexus, только если индекс подтверждён для полного пути активного проекта.
- [`code-review/`](code-review/SKILL.md) — структурированное ревью изменений: веток, диффов, pull request/merge request, коммитов и незакоммиченных правок. Помогает находить дефекты, регрессии, риски безопасности и пробелы в тестах; оформляет приоритетные замечания со ссылками на код.
- [`task-planning/`](task-planning/SKILL.md) — подготовка подробного плана реализации для одного или нескольких merge request. Включает анализ проекта, описание этапов, готовые варианты изменений, тесты и проверки; сам скилл ничего не реализует.
- [`execute-plan/`](execute-plan/SKILL.md) — выполнение уже согласованного плана по одному этапу за раз. По умолчанию каждый этап отдельно проверяется, показывается пользователю и коммитится после подтверждения; пакетное выполнение возможно только при явном ограниченном разрешении.
- [`otar-diagrams/`](otar-diagrams/SKILL.md) — создание, обновление и проверка связанных информационной и функциональной диаграмм по нотации ОТАР Газпромбанка. Скилл опирается на код и предоставленные официальные материалы; дополнительные правила, примеры и ресурсы лежат в каталоге скилла.

У каждого скилла есть `SKILL.md` с подробными инструкциями. Дополнительные материалы хранятся рядом в каталоге соответствующего скилла.

Перед редактированием на устройстве подтяните изменения (`git pull`). После изменений сохраните их коммитом и отправьте (`git push`), чтобы получить их на другом компьютере.
